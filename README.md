# 🖼️ Animated Image Layout Project
This project showcases a responsive and clean image layout built using **HTML**, **CSS**, and a touch of **GSAP** for subtle animations. The design avoids the use of `position: absolute` to ensure better scalability and responsiveness, leveraging modern layout techniques like **Flexbox**.

## 🚀 Features
- 💡 Fully responsive layout without absolute positioning  
- ✨ Smooth GSAP animations for engaging visuals  
- 🧱 Flexbox-based layout for cleaner structure  
- 🎨 Custom styling for a polished UI  

## 📁 Tech Stack
- **HTML5** – Semantic and structured markup  
- **CSS3** – Custom styles and responsive design  
- **GSAP** – Lightweight JavaScript animations

## 🛠️ How to Run
1. Clone this repository:
   ```bash
   git clone https://github.com/yourusername/image-layout-project.git
   cd image-layout-project
   ```
2. Open `index.html` in your browser.

## 🧩 Customization
You can customize:
- Image size and layout in `style.css`
- Animation settings in `script.js` (GSAP)
